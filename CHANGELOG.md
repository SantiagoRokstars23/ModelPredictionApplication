## [1.1.0] - 2026-07-29

**Resumen:** primera versión con una aplicación funcional completa (Runtime, Capa de Preparación de Variables, los 6 motores del Engine, Persistencia, un primer caso de uso de punta a punta), backtesting real sobre datos de StatsBomb, y el ciclo completo de una corrección matemática — investigación (`MODEL-019`), diseño (`MODEL-020`), implementación (`IMP-003`) y validación (`VALID-004`) de Dixon-Coles — resuelto de principio a fin. Todo lo listado debajo, hasta la sección `[1.0.0]`, forma parte de esta versión.

**Nota de versionado:** se evaluó clasificar este salto como `2.0.0` (el proyecto pasa de ser un repositorio de documentación a una aplicación con predicciones reales) — se descarta porque el criterio de Versionado Semántico para la versión MAYOR es la ruptura de un contrato público ya existente, y este proyecto no expone ninguno todavía (el endpoint HTTP ni siquiera está montado en `app/main.py`). Todo lo agregado desde `1.0.0` es funcionalidad nueva y aditiva — el caso de uso exacto que Versionado Semántico reserva para la versión MENOR.
